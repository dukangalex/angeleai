USER GUIDE使用指南 · 装好之后怎么用

下载那一步管「装上」，这一部分管「装上之后」：五步走完就能正常上网。每一步都写了点哪里、什么样算成功、不对劲先看哪；术语第一次出现，都配了一句人话解释。

  1. 1

    导入订阅

    先说人话：订阅是服务商给你的一串链接，里面装着全部节点。导入它，等于把节点一次性装进来。

    点哪里　打开 App，底部点「配置」→「添加」，四个入口选一个：事先复制好链接就点「剪切板」；有二维码点「二维码」扫；也可以点「URL」手动粘贴、点「文件」选配置文件。

    算成功　配置页出现一张新的配置卡，点一下它设为当前配置；回到首页，首页卡上能看到这份订阅的到期日和用量。

    不对劲　提示链接不对，多半是没复制全、或复制的根本不是订阅链接，重新复制再试；还是不行，翻下面排错第 1 条。

  2. 2

    选节点与策略组

    先说人话：策略组是按用途分好的节点组（比如按地区、按应用分）。你在组里点哪个节点，流量就从哪个节点出去。

    点哪里　底部点「代理」，点开一个策略组，再点你想用的那个节点。

    算成功　首页卡上的节点名变成你选的节点，旁边的状态灯是绿色，还带着一个延迟数字（比如 120ms，数字越小越快）。

    不对劲　灯是灰的，说明还没测过，点一下状态灯就会测速（只测，不会替你换节点）；灯是红的、或节点显示 Timeout，说明这个节点不通，换一个。

  3. 3

    模式与规则

    先说人话：模式决定流量怎么走。「规则模式」是 App 自动分流——国内网站直连、其余走代理，日常用它就对了；「全局」是全部走代理；「直连」是全部不走代理。

    点哪里　不用去设置里翻：首页卡的下半区就是模式切换，点「规则」。

    算成功　模式停在「规则」上；国内网站打开快，国外网站也能正常打开。

    不对劲　国内网站变慢，先看模式是不是被切到了「全局」（排错第 6 条）；国外网站打不开，先看节点的状态灯是不是红的。

  4. 4

    链式代理怎么开

    先说人话：链式代理是让流量先经过一个入口节点、再从一个出口节点出去，串成两段。一般人用不上，有固定出口需求时再开。

    点哪里　「配置」页点开配置卡的菜单 →「链式代理」→ 打开开关；先选入口（当前配置里的节点或组），再选出口（从另一个配置里选节点或组）。

    算成功　配置卡上链路状态正常，网页照常打开。

    不对劲　入口失效，整条链会直接断开，不会偷偷改成直连——这是故意的，防的是流量走错路。看到「入口 / 出口已不在配置中」的提示，是订阅更新后原来的选择没了，回链式设置重选（排错第 7 条）。

  5. 5

    更新订阅与日常维护

    点哪里　订阅更新在「配置」页：点开配置卡菜单 →「同步」立即更新；在编辑配置里还能打开自动更新、设定间隔。App 本身更新：从 GitHub Releases 下载新版，或在「关于」页点检查更新。

    算成功　首页卡上的更新时间变成刚刚，到期日和已用流量跟着当前订阅刷新，和你买的套餐对得上。

    不对劲　同步失败会弹窗写明原因，照提示处理；更新完发现分组和以前不一样，先翻排错第 5 条，多半是正常变化。

五步都走完还是不对劲？别瞎猜，按症状翻下面的排错表，照顺序查，查到哪步好了就停。

TROUBLESHOOTING排错 · 按症状对号入座

找到和你情况最像的一条，从第 1 步开始往下查，每做一步就试一下，好就停，不用全做完。

✚1 · 订阅导入失败，或导入后是空的

  1. 重新到服务商页面复制完整的订阅链接，回 App 点「剪切板」导入——App 会校验剪贴板里是不是链接，提示不对就是没复制对。
  2. 剪切板不行，换「URL」手动粘贴，或用「二维码」扫码导入。
  3. 拉订阅本身需要网络：换个网络（Wi-Fi 与移动数据互换）再试一次。
  4. 导入成功但里面没有节点：多半是订阅到期或流量用尽，看首页卡上的到期日和用量确认；没到期就联系服务商查订阅状态。

✚2 · 连上了，但网页打不开

  1. 看首页卡状态灯：红灯说明当前节点不通，去「代理」页换一个延迟数字正常的节点。
  2. 点一下状态灯重新测速，确认换好的节点是绿灯。
  3. 还打不开：更新一次订阅（配置页 → 配置卡菜单 → 同步），再重新选节点。
  4. 只有某一个网站打不开、其他都正常：换个节点再试那个网站。

✚3 · 节点大片超时（Timeout）

  1. 先换网络：Wi-Fi 和移动数据互换，再点状态灯重新测速——大片超时常常出在本地网络。
  2. 更新订阅（配置页 → 同步），排除节点列表过旧。
  3. 还是一片 Timeout：多半是服务商的节点集体故障，先挑个别能用的顶着，过段时间再测，或联系服务商。

✚4 · 延迟异常高

  1. 在「代理」页点开策略组，选延迟数字更小的节点（数字就是毫秒，越小越快）。
  2. 订阅里有「自动选择」组的话切过去，它会自动挑当前最快的节点。
  3. 换个网络再测一次对比：延迟高也可能出在你本地网络，不全是节点的问题。

✚5 · 更新订阅后，分组和以前不一样

  1. 先别慌：服务商调整了节点和分组，App 只是照新内容显示，这是正常变化，重新选一次节点即可。
  2. 如果分组还是旧的、一点没变：那是没刷新过来——到配置页对配置卡点「同步」手动更新。
  3. 同步后退出配置页再重新进入，让界面按新内容重新加载。
  4. 开了链式代理的：分组改名会让原来的入口 / 出口失效，出现断链提示时按第 7 条重选。

✚6 · 国内网站打开慢

  1. 先看模式：首页卡模式区应在「规则」。如果在「全局」，所有流量都绕代理，国内网站必然慢——切回「规则」。
  2. 模式没错还慢：更新一次订阅（配置页 → 同步），拿到最新的分流规则。
  3. 只有个别国内网站慢、其他都快：多半是那个网站自身的问题，换个时间再试。

✚7 · 链式代理断链

  1. 先看提示写的是哪一头：「入口已不在当前配置中」或「出口已不存在」——意思是订阅更新后，你原来选的节点或组被改名或删掉了。
  2. 到「配置」页 → 配置卡菜单 →「链式代理」，把失效的那一头重新选一个现在有的节点或组，保存。
  3. 暂时不用链式：直接关掉链式开关，先恢复普通用法。
  4. 断链时网页打不开是预期行为：入口失效整条链就断，App 不会偷偷改直连，重选或关掉就好。

USER GUIDEAfter install: how to actually use it

The download section gets the app onto your device; this part is about what comes after. Five steps take you from importing a subscription to day-to-day upkeep. Each step says where to tap, what success looks like, and what to check first when something's off — and every term is explained in plain words the first time it appears.

  1. 1

    Import your subscription

    In plain words: a subscription is a link from your provider that carries the whole node list. Importing it loads everything at once.

    Where　Open the app, tap Profiles at the bottom, then Add. Four ways in: copy the link first and tap Clipboard; tap QR Code to scan one; or paste the link under URL, or pick a config file under File.

    Success　A new profile card appears on the Profiles page. Tap it to make it the active profile; the home card then shows that subscription's expiry date and data usage.

    If not　If it says the link isn't right, the copy was probably incomplete, or wasn't a subscription link at all — copy it again and retry. Still failing? See problem 1 below.

  2. 2

    Pick a node and a policy group

    In plain words: a policy group is a set of nodes grouped by purpose (by region, by app, and so on). Whichever node you tap inside the group is the one your traffic leaves through.

    Where　Tap Proxies at the bottom, open a group, and tap the node you want.

    Success　The home card shows that node's name, with a green status light and a delay number next to it (e.g. 120ms — smaller is faster).

    If not　A grey light means "not tested yet" — tap the light to run a test (it only measures; it never switches your node for you). A red light, or a Timeout label on the node, means that node is down — pick another one.

  3. 3

    Mode and rules

    In plain words: the mode decides how traffic flows. Rule mode lets the app split it automatically — domestic sites go direct, everything else goes through the proxy; that's the one for daily use. Global sends everything through the proxy; Direct sends nothing through it.

    Where　No settings dive needed: the mode switch sits in the lower half of the home card. Tap Rule.

    Success　The mode stays on Rule; domestic sites load fast and foreign sites open normally.

    If not　Domestic sites suddenly slow? Check the mode hasn't been switched to Global (problem 6). A foreign site won't open? Check whether the node light is red first.

  4. 4

    Turn on chained proxy

    In plain words: a chained proxy routes traffic through an entry node first, then out through an exit node — two hops in a row. Most people never need it; turn it on only if you need a fixed exit.

    Where　On the Profiles page, open the profile card's menu → Chained Proxy → switch it on. Pick the entry (a node or group from the current profile), then the exit (a node or group from another profile).

    Success　The profile card shows the chain as healthy, and pages load as usual.

    If not　If the entry dies, the whole chain stops — it never quietly falls back to a direct connection, and that's on purpose, so traffic can't take the wrong road. A notice saying the entry or exit is no longer in the profile means a subscription update removed your pick; reselect it in chain settings (problem 7).

  5. 5

    Update subscriptions and routine upkeep

    Where　Subscription updates live on the Profiles page: open the profile card's menu → Sync for an immediate update; in Edit Profile you can also enable auto-update and set its interval. App updates: grab the new build from GitHub Releases, or use Check for Updates on the About page.

    Success　The home card's update time becomes "just now", and the expiry date and used traffic refresh to match the subscription you actually bought.

    If not　A failed sync pops up a notice stating the reason — follow what it says. Groups look different after an update? See problem 5 first; it's usually a normal change.

Done all five and something still feels wrong? Don't guess — find your symptom in the troubleshooting table below and work down its steps; stop as soon as it's fixed.

TROUBLESHOOTINGTroubleshooting · find your symptom

Find the entry closest to what you see, start at step 1, and test after each step. Stop as soon as it works — you don't have to finish the list.

✚1 · Import fails, or the imported profile is empty

  1. Copy the full subscription link again from your provider, then import via Clipboard — the app checks that the clipboard really holds a link, so a warning means the copy was wrong.
  2. If Clipboard won't take it, paste it under URL instead, or scan the QR code.
  3. Fetching a subscription needs a working network: switch between Wi-Fi and mobile data and try again.
  4. Imported fine but no nodes inside: the subscription has most likely expired or run out of traffic — check the expiry date and usage on the home card; if it's still valid, ask your provider about the subscription's status.

✚2 · Connected, but pages won't load

  1. Check the status light on the home card: red means the current node is down — go to Proxies and pick a node with a healthy delay number.
  2. Tap the status light to re-test, and confirm the new node shows green.
  3. Still stuck: update the subscription (Profiles → profile card menu → Sync), then pick a node again.
  4. Only one site fails while everything else works: switch nodes and try that site again.

✚3 · Lots of nodes time out (Timeout)

  1. Switch networks first — Wi-Fi ↔ mobile data — then tap the status light to re-test. Mass timeouts are often your local network.
  2. Update the subscription (Profiles → Sync) to rule out a stale node list.
  3. Still timing out everywhere: the provider's nodes are most likely down as a group. Use whichever node still works, then retest later or contact the provider.

✚4 · Delay is unusually high

  1. Open the group on the Proxies page and pick a node with a smaller delay number (the number is milliseconds — smaller is faster).
  2. If your subscription has an "Auto" group, switch to it — it keeps picking the currently fastest node for you.
  3. Retest on a different network: high delay can come from your local connection, not the node.

✚5 · Groups look different after a subscription update

  1. Don't panic: your provider changed their nodes and groups, and the app is simply showing the new content. Just pick your node again.
  2. If nothing changed at all and the old groups are still there, the refresh didn't land — open the profile card menu on the Profiles page and tap Sync manually.
  3. After syncing, leave the Profiles page and come back so the UI reloads with the new content.
  4. Using a chained proxy? A renamed group can invalidate your entry/exit picks — if you get a chain-broken notice, reselect them per problem 7.

✚6 · Domestic sites load slowly

  1. Check the mode first: the home card's mode area should say Rule. On Global, every byte detours through the proxy and domestic sites crawl — switch back to Rule.
  2. Mode is right but it's still slow: update the subscription (Profiles → Sync) to pick up the latest routing rules.
  3. Only one domestic site is slow while others are fine: that's most likely the site itself — try again later.

✚7 · Chained proxy is broken

  1. Read which end the notice names: the entry is no longer in the current profile, or the exit profile/target is gone — a subscription update renamed or deleted what you had picked.
  2. Go to Profiles → profile card menu → Chained Proxy, and reselect the broken end from the nodes and groups that exist now, then save.
  3. Don't need the chain right now? Just switch chained proxy off and go back to normal use.
  4. Pages failing while the chain is broken is expected: a dead entry stops the whole chain, and the app never falls back to direct silently. Reselect or switch it off and you're back.
